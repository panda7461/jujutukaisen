# 呪力バトル -CURSE BATTLE-

呪術廻戦の世界観にインスパイアされた、オリジナルのブラウザ用トップダウン・アクションバトルゲームです。
キャラクター・敵はすべてオリジナル創作で、外部の画像や音声素材は使用していません(Canvas + 絵文字のみで描画)。

## 遊び方

1. `index.html` をブラウザで開く(ビルド不要・サーバー不要)
2. タイトル画面で「はじめる」を押す
3. 3人の呪術師から1人を選択してゲーム開始
4. 押し寄せる呪霊(WAVE 1〜4)を倒し、最終WAVEの特級呪霊を撃破すればクリア

### 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー または `W` `A` `S` `D` |
| 通常攻撃 | `Space` |
| 秘奥義(領域展開級の必殺技) | `X`(呪力ゲージが満タンの時のみ発動) |

- 通常攻撃を敵に当てると呪力ゲージが溜まります。
- 呪力ゲージが満タンになったら `X` で秘奥義を発動し、周囲の敵に大ダメージを与えられます。
- 敵に接触されるとダメージを受けます。HPが0になるとゲームオーバーです。

## キャラクター

| 名前 | タイプ | 特徴 |
| --- | --- | --- |
| 朧井 陽真 | 均衡型 | 攻撃・速度のバランス型 |
| 氷室 瑠花 | 速攻型 | 高速移動・手数重視、HPは低め |
| 巌流 剛 | 重装型 | 高HP・高火力の前衛タイプ |

## 技術構成

- Vanilla JavaScript(フレームワーク・ビルドツール不使用)
- HTML5 Canvas によるゲーム描画
- ファイル構成:
  - `index.html` — 画面構造(タイトル / キャラ選択 / ゲーム / リザルト)
  - `style.css` — スタイル
  - `game.js` — ゲームロジック本体
